# 领域边界

贯通口袋公园资产、共建责任、巡检维修、开放状态和资金履约。

现有领域资料围绕以下边界组织：

- 公共空间档案
- 设施资产谱系
- 巡检与风险处置
- 共建履约资金
- 开放历史查询

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。

## 服务规则

`src/park_service.py` 将上述边界落实为可执行规则：

- 领域事实一律带生效区间 `[valid_from, valid_to)`，改写等于终止旧记录并登记新记录
- 每日计划先于现场证据；证据必须对应当日应检项目，高风险证据自动封闭所在区域并生成处置单
- 报修按设施或区域并入未结处置单；进度通知按居民逐人送达
- 复检人不得是维修人；重新开放日期不得早于风险解除日期
- 付款按确认工程量分段审批；调整（返工、撤销、质保追偿）只新增带符号的调整记录，不改动原付款
- 养护移交只切换移交日之后的责任；未解除风险和质保追偿留在原责任方
- 状态完全由事件日志重放得到，系统停机不丢失围挡、待修和审批中的事实
